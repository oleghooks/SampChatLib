# SampChatLib
Библиотека для взаимодействия с чатом Amazing Online\
Импортирована с AHK v1.1 на C# в виде библиотеки с одной единственной функцией "SendChat" из CRMP_UDF.\
Разработчиком оригинальной CRMP UDF на AHK является vk.com/idDrygok (https://github.com/Drygok/CRMP_UDF)\

# Почему на эту библиотеку ругается антивирус
Библиотека имеет похожие сигнатуры с читами, но при этом читом не является, она абсолютна легальна как и CRMP UDF, так как по сути ей и является, просто импортирована другой язык программирования для удобства\
Вы можете самостоятельно скопировать исходный код библиотеки которые находится в файле Class1.cs и отправить в любую ИИ с вопросом "Опасен ли данный код для моего компьютера"

## Это вирус?

По предоставленному коду:

❌ Нет признаков:

- кражи паролей; 
- работы с браузерами; 
- кейлоггера; 
- загрузки файлов;
- шифрования данных; 
- майнинга;
- доступа к камере или микрофону. 

## Что настораживает антивирус

Используются функции:
```
VirtualAllocEx
WriteProcessMemory
CreateRemoteThread
```
Это классический механизм инжекта в чужой процесс.\
\
Такие же API используют:\
\
читы;\
трейнеры;\
некоторые вирусы;\
программы автоматизации игр.
\
Поэтому антивирус может ругаться даже если DLL всего лишь отправляет сообщения в чат.
